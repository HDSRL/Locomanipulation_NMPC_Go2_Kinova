# SRB_NMPC_Casadi_Formulation

Standalone project that builds the symbolic A1/Go2 + Kinova NMPC in CasADi and generates the solver as C code.

`a1_kinova_nmpccodegen` (`src/a1_kinova_nmpccodegen.cpp`) builds the problem, generates C code, and compiles two shared libraries:

- `a1_kinova_nlp_code.so`: the IPOPT solver
- `a1_kinova_nlp_code_f.so`: the dynamics functions used by the main project

Don't run it by hand. From the repository root, run:

```bash
./runCodegenA1K.sh
```

The script builds this project, runs the generator from `SRB_NMPC_Casadi_Formulation/build/`, and copies both libraries into the main `build/` folder.

The arm mass matrix and gravity vector (`dynamics/D_mat_pin.casadi`, `dynamics/G_vec_pin.casadi`) are generated by `dynamics/kinova_dynamics.ipynb`, which requires Pinocchio with CasADi bindings.

See the top-level `README.md` for dependencies and the full build.
